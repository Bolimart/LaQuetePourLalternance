# La quête pour l'alternance.

_Dans un Univers pas très éloigné du nôtre, un groupe d'étudiant cherche une alternance, malheureusement, ce n'est pas si simple... Après plusieurs mois de recherche, l'un d'eux trouve finalement cet artéfact sacré..._
_Mais la fierté et l'orgueil consommat l'élève, et il devint insupportable à frequenter, et surtout, rendit tout le monde jaloux. Si bien que ces anciens camarades se joignirent pour l'affronter et s'accaparer son alternance._
